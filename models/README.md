# Modelos 3D

Sube aquí los modelos del mundo en formato `.glb` o `.gltf`.

Recomendado: usa `.glb` con las texturas empaquetadas dentro. Después, añade cada archivo a la lista `MODEL_URLS` de `../index.html`, con su posición, escala y rotación.

Ejemplo: `{ url: './models/mi-modelo.glb', position: [0, 0, -10], scale: 1, rotationY: 0 }`.
